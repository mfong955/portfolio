Full Stack Breakdown

Across these two projects, the full stack spans frontend frameworks, managed backend services, AI APIs, data infrastructure, and deployment pipelines:

Unbias AI

  • Next.js + React: Full-stack web framework handling routing, server-side rendering, and API routes—single codebase for frontend and backend logic
  • Tailwind CSS: Utility-first styling, enabling rapid UI iteration without a design system
  • Supabase: Managed PostgreSQL database with built-in auth—handling user accounts, session management, and data persistence without standing up a backend server
  • Vercel: Edge deployment with CI/CD on every push—preview deployments, environment variable management, and global CDN out of the box
  • Stripe: Payment integration for subscription management—webhooks, customer portal, and billing lifecycle
  • Claude API: Powers all eight AI tools—structured prompting across different task types (debate, analysis, policy modeling, content generation)

Airbyte Issue Analyst

  • PyAirbyte: Production source-github connector (Docker-backed) ingesting live issues from airbytehq/airbyte—no mocked data
  • DuckDB: Embedded analytical database persisted to disk—stores raw issues and Claude-enriched analysis, queryable via SQL
  • Claude API: Two distinct usage patterns: batch structured extraction (JSON enrichment per issue) and conversational text-to-SQL (two-call agent for Q&A)
  • Streamlit: Rapid demo UI with interactive dashboard, bar chart drill-down, and natural language query interface
  • Docker: Required by PyAirbyte's connector runtime—managed as a dependency of the ingest pipeline
  • Python 3.11+: Orchestration, pipeline logic, and agent implementation across ingest, enrichment, and query layers
